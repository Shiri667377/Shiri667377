## ✈️ European Flight Network Analysis

A graph-based analysis of the European air transportation network using real-world OpenFlights data.

### Highlights

- Modeled airports and routes as a graph
- Analyzed airport importance using:
  - Degree Centrality
  - Betweenness Centrality
  - Closeness Centrality
  - PageRank
- Applied the **Louvain algorithm** for community detection
- Examined clustering and inter-community connections
- Simulated random and targeted airport removals
- Analyzed network robustness and structural vulnerabilities

### Tech Stack

`Python` `NetworkX` `Pandas` `Jupyter` `Graph Algorithms` `Data Analysis`

🔗 [View Repository](https://github.com/Shiri667377/european-flight-network-analysis)
